# DeeperGCN Cora Reproduction

`benchmark_component.py` compares the operator stage against the stable
all-NPU semantic baseline. `benchmark_deepergcn_cora_e2e.py` trains or loads an
eight-layer PyG DeeperGCN checkpoint and compares complete model inference.
`benchmark_genconv_value_gate.py` is the authoritative performance entrypoint:
it scans official same-host CPU threads, audits official NPU eager, global
padding and power-of-two degree-bucketed all-NPU baselines, and measures custom
resident plus host-to-host complete-model paths.

The checkpoint is generated by the benchmark and is intentionally not stored
in source control. The recorded checkpoint SHA-256 and all raw measurements
are in `docs/benchmark.md` and the JSON files in this directory.

The scripts require PyG's cached Cora dataset, an Ascend 910B device, and a
Release build of this package. Pass explicit paths for the dataset, build,
checkpoint, and output JSON; use `--copies 1 2 4` for the reported scales.
The benchmark prepares persistent workspace and caller-owned output buffers for
every learned temperature before timing. The checked-in formal result uses
three warmups and ten iterations and is stored in
`genconv_same_host_value_gate_20260902.json`.

Shared model, graph preparation, operator binding and timing live in
`genconv_common.py`. Each benchmark case owns its graph and callbacks; validation
counters are instance state. CPU regression tests cover native padded and bucketed
aggregation, exact staged-versus-PyG model output, independent callback state,
and invalid timing/result inputs:

```bash
python -m pytest tests -q
```

Run that command from the operator directory with NumPy, pytest, PyTorch and
PyG installed. Model-helper tests skip when PyTorch or PyG is unavailable.
