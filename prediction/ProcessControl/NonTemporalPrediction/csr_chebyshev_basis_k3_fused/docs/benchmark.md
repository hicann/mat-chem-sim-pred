# Benchmark Evidence

The source model is the maintained PyG citation ChebNet: two `ChebConv` layers,
K=3, hidden width 16, on Cora. The exact call is the recurrence implemented by
`torch_geometric/nn/conv/cheb_conv.py` at PyG revision
`003c3cd8a10520567ceaeda619f0315e30ec2f66`. Cora has 2,708 nodes, 1,433 input
features, seven classes, and 13,264 normalized Laplacian edges including loops.
The three cases use one, two, and four disjoint copies.

Environment: Ascend 910B3 device 6, CANN 8.1.RC1.alpha001, PyTorch 2.5,
torch_npu 2.5.1, PyG 2.9.0, FP32. TorchAir was unavailable. The strong native
baseline caches the identical PyG normalization and uses resident torch_npu
gather, weighted `index_add`, recurrence, and stack. The custom path replaces
only this basis generation. Both retain all six trained Linear calls.

A Level1 torch_npu profile records all NPU kernels inside the complete native
model call. The basis numerator contains only the exact kernels generated by
`features[source]`, weighted multiplication, `index_add_`, recurrence, and
stack (`Index`, `InplaceIndexAdd`, `Mul`, `ZerosLike`, `Sub`, and `Pack`). It
excludes Linear `MatMul/Add`, ReLU, and LogSoftmax kernels.
